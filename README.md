# MediBrief

**体調メモを、診察で伝えやすい形に整理するWebアプリ。**

「なんとなく体調が悪い」を自由に書くと、病院・クリニックで医師に伝えやすい7項目の受診メモに整理します。
コピーしてスマホで見せる、印刷して持って行く、といった使い方ができます。

> **診断ではありません。** 強い症状や不安がある場合は医療機関へ相談してください。
> このアプリは病名・薬・緊急度の判断を一切しません。受診**前**のメモ整理ツールです。

---

## 目的

診察は時間が限られていて、緊張すると伝えたいことを忘れがちです。
MediBrief は「何を、どの順番で伝えるか」を先に整理しておくことで、

- 伝え忘れを減らす
- 症状の経過（いつから・どう変わったか）を言葉にしておく
- 医師に聞きたいことを、質問の形で用意しておく

ことを助けます。整理するだけなので、医学的な判断はユーザーと医師に委ねます。

## 使い方

```bash
npm install
npm run dev
# http://localhost:3000 を開く
```

1. 「体調や困っていること」に、話し言葉のまま自由に書く（`例1〜例3`のボタンで入力例が入ります）
2. **受診メモを作る** を押す
3. 右（スマホでは下）に7項目の受診メモが出る
4. **コピー** でテキストとして持ち出す／**印刷** で紙に出す
5. **クリア** で入力と結果を消す

APIキーの設定は不要です。既定では入力内容はブラウザの中だけで処理され、外部に送信も保存もされません。

### 整理される7項目

| 項目 | 入るもの |
| --- | --- |
| 主な困りごと | いちばん困っている症状（「喉が痛くて」→「のどの痛み」のように言い換え） |
| いつから | 「昨日の夜から：のどの痛み」のように、時期と症状を組にしたもの |
| 症状の変化 | 強くなった・楽になった・時間帯による差など |
| 関係ありそうなこと | 睡眠・食事・仕事・ストレスなど、思い当たること |
| 服薬・持病・アレルギー | 飲んだ薬（市販薬も）、通院中の病気、アレルギー |
| 医師に聞きたいこと | 書かれた不安をもとに組み立てた、**医師に尋ねる質問文** |
| 伝え忘れ防止メモ | 空欄になっている項目の補い方＋持ち物チェック |

入力から拾えなかった項目は空欄のまま、「何を書き足すと伝わりやすいか」だけを案内します（推測で埋めません）。

## 技術スタック

- **Next.js 16**（App Router / Turbopack）
- **TypeScript**
- **Tailwind CSS v4**
- 整理ロジックは**依存ライブラリなしのルールベース**（`lib/organizer/rule-based.ts`）

```
app/
  page.tsx                  画面全体（サーバーコンポーネント）
  layout.tsx / globals.css
  api/organize/route.ts     任意のAI経路（APIキーが無ければルールベースを返す）
components/
  MemoBuilder.tsx           入力と結果をつなぐ本体（状態はここだけ）
  SymptomForm.tsx           入力欄・入力例・作成/クリアボタン
  MemoResult.tsx            受診メモの表示・コピー・印刷
  MemoSectionCard.tsx       項目1つ分のカード
  DisclaimerNotice.tsx      「診断ではありません」の注意書き
lib/
  types.ts                  VisitMemo / MemoSection / MemoOrganizer
  sections.ts               7項目の見出し・説明・空欄ガイド
  format.ts                 コピー用テキストと注意書き
  examples.ts               入力例3つ
  organizer/
    index.ts                整理ロジックの差し替えポイント
    rule-based.ts           既定の整理ロジック
    remote.ts               /api/organize を呼ぶ実装＋応答の検証
    dictionaries.ts         症状の言い換え・振り分けの手がかり語
```

### 整理ロジックの仕組み（ルールベース）

1. 入力を句読点で短い文に分ける
2. 薬の名前（「痛み止め」など）を伏せてから、症状の言葉を探して言い換える
3. 時期の表現（「昨日の夜から」「3日前から」）を正規表現で抜き出し、同じ文の症状と組にする
4. 残りの文を手がかり語で振り分ける（質問 → 服薬 → 変化 → 状況 の優先順）
5. どこにも入らなかった文も必ずどこかに残す（入力を捨てない）
6. 空欄の項目から「伝え忘れ防止メモ」を作る

否定表現も見ています。「吐いてはいない」は症状として拾わず、そのままの言葉で残します。

### あとからAIに差し替える

`MemoOrganizer` インターフェース（`lib/types.ts`）に合わせるだけで、画面側の変更は不要です。
OpenAI を使う経路は最初から入っています。

```bash
cp .env.example .env.local
```

```env
NEXT_PUBLIC_MEMO_PROVIDER=api
OPENAI_API_KEY=sk-xxxxxxxx
OPENAI_MODEL=gpt-4o-mini
```

- `NEXT_PUBLIC_MEMO_PROVIDER=api` にすると `/api/organize` 経由になります
- APIキーが無いとき・API呼び出しが失敗したときは、サーバー側でルールベースに戻します（アプリは必ず動きます）
- 別のサービスに変える場合は `app/api/organize/route.ts` の `callOpenAI()` だけ差し替えてください
- AIへの指示（`SYSTEM_PROMPT`）でも、病名・薬・緊急度の出力を明示的に禁止しています

> `api` に切り替えると入力内容が外部APIに送信されます。体調は機微な情報なので、送信先の規約を確認してから使ってください。

## 注意事項

- **これは医療診断AIではありません。** 病名の断定、薬の提案、緊急度の判定、治療アドバイスは行いません。
- 整理結果はあくまで下書きです。事実と違うところは、そのまま直して使ってください。
- ルールベースなので、言い方によっては項目の振り分けを間違えることがあります（誤って項目が変わっても、入力した文自体は必ずどこかに残ります）。
- 強い痛み、息苦しさ、意識の異常など、心配な症状があるときはメモを作るより先に医療機関へ相談してください。
- 既定（`rule`）では入力内容を送信も保存もしません。ブラウザを閉じると消えます。
- 医療機関で使う場合も、記録の正式な代わりにはなりません。

## 今後の拡張案

- **結果の手直し**：生成された項目をその場で編集・並び替えできるようにする
- **AI整理の本格対応**：`api` プロバイダを既定にできる品質まで詰める（禁止事項の自動チェックを含む）
- **保存と再利用**：`localStorage` に下書きを保存し、通院ごとの経過を並べて見られるようにする
- **経過の記録**：同じ症状のメモを日付で並べ、「いつから・どう変わったか」を自動でまとめる
- **音声入力**：話した内容をそのまま入力欄に入れる（Web Speech API）
- **家族の代理入力**：本人以外が書く場合の視点（「本人は〜と言っています」）に対応
- **多言語**：やさしい日本語・英語・中国語の受診メモを出力する
- **PDF出力**：印刷用レイアウトを整えてPDFで保存できるようにする
- **辞書の拡充とテスト**：症状の言い換え辞書を増やし、振り分けの自動テストを用意する
- **問診票テンプレート**：診療科ごとに聞かれやすい項目を追加表示する
